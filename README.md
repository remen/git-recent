# git-recent
Interactively checkout local branch, sorted by most recent commit

![t-rec](https://github.com/user-attachments/assets/47ddd678-beb8-4b3b-b862-408e45c6383f)

# Installation

Copy `git-recent` into a directory in your `$PATH`.

# Usage

```shell
$ git recent
```

# Dependencies

- `awk` - Typically already installed
- `fzf` - Install with e.g. `brew install fzf`
